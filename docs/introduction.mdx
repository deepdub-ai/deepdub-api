## Welcome to Deepdub

Deepdub provides voice AI APIs in both directions. Text-to-Speech turns text into natural, expressive speech with voice cloning, accent control, and real-time streaming. Speech-to-Text transcribes live Hebrew and English audio word by word as it is spoken. Use them together for voice agents and call centers, or on their own for voiceover, localization, and transcription.

<Tab title="Speech-to-Text (Python)">
```python
import asyncio
import json
import wave

import websockets  # pip install "websockets>=14"

async def main():
    with wave.open("sample.wav") as w:  # 16 kHz mono 16-bit
        pcm = w.readframes(w.getnframes())

    headers = {"Authorization": "Bearer dd-00000000000000000000000065c9cbfe"}
    url = "wss://wsgw.deepdub.ai/transcribe-websocket"
    async with websockets.connect(url, additional_headers=headers) as ws:
        await ws.send(json.dumps({
            "model": "stt-egf",
            "audio_format": "pcm_s16le",
            "sample_rate": 16000,
            "num_channels": 1,
            "language_hints": ["en"],
        }))
        for i in range(0, len(pcm), 3200):  # 100 ms per frame
            await ws.send(pcm[i:i + 3200])
            await asyncio.sleep(0.1)
        await ws.send("")  # end of audio

        words = []
        async for msg in ws:
            data = json.loads(msg)
            words += [t["text"] for t in data.get("tokens", []) if t["is_final"]]
            if data.get("finished"):
                break
        print("".join(words).strip())

asyncio.run(main())
```

## API access

| API | Endpoint | Use case |
|--------|----------|----------|
| **Text-to-Speech REST** | `https://restapi.deepdub.ai/api/v1` | Streaming audio generation, voice management |
| **Text-to-Speech WebSocket** | `wss://wsapi.deepdub.ai/open` | Real-time streaming with chunked audio delivery |
| **Speech-to-Text WebSocket** | `wss://wsgw.deepdub.ai/transcribe-websocket` | Live transcription, word by word |
