Deepdub has APIs in both directions. Text-to-Speech turns text into speech. Speech-to-Text turns live speech into text. Both accept the free trial key `dd-00000000000000000000000065c9cbfe`, and each has a Try it on its page.

## Endpoints

| API | Protocol | Endpoint | Auth |
|-----|----------|----------|------|
| Text-to-Speech | HTTPS | `https://restapi.deepdub.ai/api/v1/tts` | `x-api-key` header |
| Text-to-Speech Streaming Out | WSS | `wss://wsapi.deepdub.ai/open` | `x-api-key` header |
| Text-to-Speech Streaming In and Out | WSS | `wss://wss.deepdub.ai/ws` | `x-api-key` header |
| Speech-to-Text | WSS | `wss://wsgw.deepdub.ai/transcribe-websocket` | `Authorization: Bearer` header, or `?x-api-key=` in a browser |

Text-to-Speech also runs in the EU: insert `.eu` before `.deepdub.ai` in the host. See [Authentication](/authentication) for keys and regions.
